# The Future Point Library

Simple static website for The Future Point Library, Maharajganj, Uttar Pradesh.

## Open in Chrome

1. Open the project folder.
2. Double-click the root `index.html`.

All pages, styles, events and interactions work without Node.js, npm or a local server.

## Deploy

Upload the project files to any static hosting service, keeping the `Content` folder beside the root `index.html`. The contact form opens the visitor's email app with a prepared message.
