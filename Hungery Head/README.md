# Hungry Head Restaurant

A responsive vanilla HTML, CSS, and JavaScript restaurant website for Hungry Head Restaurant, Varanasi RC.

## Run locally

Open `index.html` directly in a browser, or run a simple local server from this folder:

```powershell
python -m http.server 5500
```

Then visit `http://localhost:5500`.

The feedback form stores demo submissions in the browser's `localStorage` under `hungryHeadFeedback`.
